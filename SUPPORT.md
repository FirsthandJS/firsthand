# Support

## Questions and discussion

Open a **GitHub Discussion** for questions about using Firsthand, design questions,
or "is this the right tool for X".

## Bugs

Open a **GitHub Issue** with:

- the Firsthand version, the browser and its version,
- a minimal reproduction — ideally a link to a StackBlitz or a small repository,
- what you expected and what happened instead.

A reproduction that someone else can run is worth more than any amount of
description.

## Performance reports

Performance issues need numbers. Please include:

- the benchmark or profile that shows the problem,
- the machine, the browser and the build mode,
- what you compared against.

Run `npm run bench` and attach the JSON result file if you can. See
[`PERFORMANCE_PLAN.md`](PERFORMANCE_PLAN.md) for the measurement rules the
project holds itself to.

## Security

Do not open a public issue for a vulnerability. See [`SECURITY.md`](SECURITY.md).

## Commercial support

There is none. This is a volunteer-maintained open source project.
